# DESCRIPTIVE / GROUPED-DATA RULES

Location measures:
- mean, median, mode, quartiles, percentiles
- mean vs median and quartile asymmetry may indicate skewness
- tails/outliers matter; centre alone is incomplete

Dispersion:
- range, IQR, variance, SD, coefficient of variation
- coefficient of variation is dimensionless and should be used to compare dispersion across different units/scales or structurally different means
- do not declare a single distribution "highly dispersed" from CV alone

Grouped interval-class data:
- frequency density = relative frequency / class width
- for unequal class widths, modal class is the class with highest density, not necessarily highest frequency
- grouped means/quantiles are approximations because raw values are unavailable
- if interpolation/uniform-within-class assumption is used, label it as an approximation
